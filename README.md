# GLINT Research Website

The official website for **GLINT** — Gastroenterology London Investigative Network for Trainees.

Built with [Astro](https://astro.build), [TinaCMS](https://tina.io), [React](https://react.dev), and [Tailwind CSS](https://tailwindcss.com). Hosted on [Vercel](https://vercel.com).

## Quick Start

```bash
npm install
npm run dev:tina
```

Site at http://localhost:4321 — CMS admin at http://localhost:4321/admin/index.html
